# موقع نبراس المعرفة للدراسات والاستشارات (NMSC)

## الملفات
- `index.html`: الرئيسية
- `about.html`: من نحن (التعريف والرؤية والرسالة والقيم والأهداف)
- `services.html`: دليل الخدمات
- `statistics.html`: التحليل الإحصائي
- `research.html`: البحث العلمي
- `development.html`: تطوير المؤسسات
- `projects.html`: إدارة المشاريع
- `sectors.html`: الجهات ذات العلاقة
- `contact.html`: التواصل ونموذج طلب الخدمة عبر واتساب
- `styles.css`: التصميم المتجاوب
- `script.js`: قائمة الجوال ونموذج التواصل
- `assets/logo.jpg`: الشعار المرفق

## تجربة الموقع
افتح `index.html` في المتصفح.

## النشر على GitHub وRender
1. ارفع جميع محتويات المجلد إلى مستودع GitHub.
2. في Render اختر **New + → Static Site** واربط المستودع.
3. اترك **Build Command** فارغًا.
4. اجعل **Publish Directory** هو `.` ثم اضغط Deploy.

## ملاحظات قبل النشر
- نموذج التواصل يفتح واتساب على الرقم الموجود في الموقع ولا يحفظ البيانات على خادم.
- روابط منصات التواصل الاجتماعي غير مضافة لأنها لم تُزوّد بعد.
- يمكن تعديل رقم واتساب في `contact.html` و`script.js` إذا لزم الأمر.
